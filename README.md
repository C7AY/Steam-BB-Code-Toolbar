# Steam BB Code Toolbar

Браузерное расширение для Steam, которое добавляет панель инструментов с BB-кодами к текстовым полям на сайтах Steam.

## ✨ Основные возможности

- 🎨 **15 BB-кодов**: жирный, курсив, подчеркнутый, зачеркнутый, заголовки (H1-H3), цитаты, спойлеры, код, ссылки, списки, таблицы, горизонтальная линия
- 🚀 **Автоматическое обнаружение**: панель добавляется ко всем textarea на страницах Steam, кроме встроенных окон (скриншоты, иллюстрации, видео)
- 🎯 **Стилизация под Steam**: дизайн панели выполнен в стиле интерфейса Steam


## 📦 Установка

### Chrome / Edge / Brave / Opera

1. Скачайте все файлы расширения
2. Откройте `chrome://extensions/` (или `edge://extensions/` для Edge)
3. Включите "Режим разработчика" в правом верхнем углу
4. Нажмите "Загрузить распакованное расширение"
5. Выберите папку с файлами расширения

Или 
3. Включите "Режим разработчика" в правом верхнем углу
4. Перетащите файл steam-bb-toolbar-v1.0.crx в окно расширений и установите его.

### Firefox

1. Скачайте все файлы расширения
2. Откройте `about:debugging#/runtime/this-firefox`
3. Нажмите "Загрузить временное дополнение"
4. Выберите файл `manifest.json`


## 📝 Использование

1. Перейдите на любую страницу Steam (steamcommunity.com или store.steampowered.com)
2. Найдите текстовое поле (например, для написания обзора)
3. Панель BB-кодов автоматически появится над полем
4. Выделите текст и нажмите на нужную кнопку
5. Текст будет обернут в соответствующие BB-теги

## 🎨 Доступные BB-коды

| Кнопка | Описание | Результат |
|--------|----------|-----------|
| **B** | Жирный текст | `[b]текст[/b]` |
| **I** | Курсив | `[i]текст[/i]` |
| **U** | Подчеркнутый | `[u]текст[/u]` |
| **S** | Зачеркнутый | `[strike]текст[/strike]` |
| **H1** | Заголовок 1 | `[h1]текст[/h1]` |
| **H2** | Заголовок 2 | `[h2]текст[/h2]` |
| **H3** | Заголовок 3 | `[h3]текст[/h3]` |
| 💬 | Цитата | `[quote]текст[/quote]` |
| 👁️ | Спойлер | `[spoiler]текст[/spoiler]` |
| 👩🏻‍💻 | Код | `[code]текст[/code]` |
| 🔗 | Ссылка | `[url=...]текст[/url]` |
| 📝 | Список | `[list][*]пункт[/list]` |
| 🔢 | Нумерованный список | `[olist][*]пункт[/olist]` |
| 📊 | Таблица | `[table][tr][th]...[/table]` |
| — | Горизонтальная линия | `[hr][/hr]` |
